### Week of 4/8-4/15: 
- Max continued to work on the same issue from last week because it required more time to fully fix the bug. Scenes were being saved using string names which resulted in unnamed scenes being added to the closing scenes list as an empty string that would be compared to other closed scenes. I changed this to use ints instead so that each page being closed has a unique number to close. This fix took an hour and a half to complete.
- The pull request was blocked due to some styling issues so that took about a half an hour to figure out how to get pre-commit working.
- [Issue #118484](https://github.com/godotengine/godot/issues/118484) [PR](https://github.com/godotengine/godot/pull/118502) This issue was for Godot's "Distraction Free Mode". When toggled, only the side menus would close. One user thought that toggling DFM should also hide the bottom panel as well so I went ahead and fixed that. This took about three and a half hours due to trying to find the necessary components in the files, rebuilding the project, testing, performing style checks, and finally creating the pull request.
- [Issue #118574](https://github.com/godotengine/godot/issues/118574) [PR](https://github.com/godotengine/godot/pull/118592) This issue was submitted for when an empty "AudioStreamOggVorbis" (not entirely sure what that is haha) resource is created in the editor and assigned the an audio streamer. When assigned and looking at the streamer in Godot's inspector, the terminal would spam an error. I fixed this to a silent error message as an empty "AudioStreamOggVorbis" object is an expected behavior when creating it as it has not yet been assigned. This took me about an hour to do as I am now getting a little more comfortable with the workflow of contributing to this project.
### Weeks of 4/15-4/29
- [Issue #118763](https://github.com/godotengine/godot/issues/118763) [PR](https://github.com/godotengine/godot/pull/118980) This issue was submitted because newly created GDScripts were unable to inherit nothing. As this is a major element in programming, it seemed like a major oversight that these scripts would cause errors if attempting to inherit nothing. I fixed this by changing what value for the inheritence gets passed to the gdscript editor from the script creation dialog. This error took me an hour and a half to complete.
- [Issue #118974](https://github.com/godotengine/godot/issues/118974) [PR](https://github.com/godotengine/godot/pull/118986) This issue involved changing the slider values in Inspector. When dragging the slider values, the mouse would automatically move to the handle instead of staying where it is or randomly jump to the center of the viewport. I fixed the mouse moving to the handle but it moving to the center of the viewport reflects a deeper problem that will require more work. So far, I put 3 hours into this.
