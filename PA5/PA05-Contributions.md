### Weeks of 4/15-4/29
- [Issue #118763](https://github.com/godotengine/godot/issues/118763) [PR](https://github.com/godotengine/godot/pull/118980) This issue was submitted because newly created GDScripts were unable to inherit nothing. As this is a major element in programming, it seemed like a major oversight that these scripts would cause errors if attempting to inherit nothing. I fixed this by changing what value for the inheritence gets passed to the gdscript editor from the script creation dialog. This error took me an hour and a half to complete. UPDATE: a few people got back to me on my PR about this fix potentially breaking things and also about displaying a message about implicitly extending another script. I took another look at it and saw that my fix would indeed break when using other languages other than GDScript. I added a guard check so that inheriting nothing using any other language wouldn't allow the script to be created and added a dialog informing the user that a script inheriting nothing implicitly inherits RefCounted. This update to my PR added another hour and a half (total for PR: 3 hours)

- [Issue #118768](https://github.com/godotengine/godot/issues/118768) [PR](https://github.com/godotengine/godot/pull/119022) This issue involved a calculation error when calling the method map_get_closed_point_normal() in the script editor.
